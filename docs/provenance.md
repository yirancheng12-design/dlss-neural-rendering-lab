# Provenance, rights and privacy

[Home](../README.md)

[evidence/manifest.json](../evidence/manifest.json) inventories original archival files from commit `f494230c3692b156b2bcf1ca9ab2aaa8084d0ff1`. Evidence, scripts, configs and duplicate trees are preserved byte-for-byte. Hashes detect change; they are not independent signatures or proof that runtime claims are correct.

New English summaries link original records without replacing mostly Chinese reports. Reports describe different investigation stages; see the [timeline](findings.md). The official background source linked from the README was checked on 2026-10-25 and does not certify these community tests.

Some records contain Windows account names, installation paths, timestamps, process IDs and machine-specific context. The old claim that all identifiers were anonymized was inaccurate. The inspector collects no new game/process information. Review new text and screenshots for personal paths, serials, account details and tokens before submitting.
